# 3.2 觸發 Artifacts 的正確方式

有時候你叫 Claude 做一個互動工具，它卻只給你一堆程式碼。這不是它故意整你，而是你的 prompt 沒有觸發 Artifacts 模式。

## 會觸發 Artifacts 的關鍵字

在你的 prompt 裡加入這些關鍵詞，Claude 就知道你要的是「看得到的東西」：

- 「請用 **Artifacts** 幫我做⋯⋯」（最直接）
- 「做一個**互動的**⋯⋯」
- 「用 **HTML** 生成⋯⋯」
- 「用 **React** 做一個⋯⋯」
- 「幫我**視覺化**⋯⋯」
- 「做一個**可以操作的**⋯⋯」

## 不會觸發的情況

- 「幫我寫一段程式碼」→ 它只會給你程式碼文字
- 「解釋 HTML 是什麼」→ 它會用文字解釋，不會生成東西
- 問答型對話 → 不需要 Artifacts

## 如果還是不觸發怎麼辦？

直接告訴它：

> 「請不要只給我程式碼，用 Artifacts 功能直接生成一個可以互動的預覽畫面。」

## Pro Tips

1. **一次做一件事**：不要在一個 prompt 裡要求做三個不同的 Artifacts。一次一個，做完再做下一個。
2. **先描述功能，再描述外觀**：Claude 更擅長「先讓它動起來」，然後再調整樣式。
3. **給尺寸提示**：如果你在意大小，可以說「適合手機螢幕」或「寬度佔滿畫面」。
