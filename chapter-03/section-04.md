# 3.4 實戰二：個人名片網頁

這次我們做一個更實用的東西 — 一個可以分享給別人的個人簡介頁面。

## Prompt

> 「請用 Artifacts 做一個個人名片式的網頁。資料如下：
>
> - 名字：CW
> - 職稱：Product Manager
> - 一句話自介：『用 AI 把點子變成產品的人。』
> - 聯絡方式：Email（cw@example.com）、LinkedIn、GitHub
>
> 設計要求：
> - 深色背景（#1a1a2e）+ 亮色文字
> - 左邊放一個圓形的頭像佔位（用灰色圓圈代替就好）
> - 右邊放文字資訊
> - 聯絡方式用圖示按鈕，hover 時有亮光效果
> - 整體風格：簡潔、有質感、像高級名片
> - 手機版要自動調整排版（上下排列）」

## 為什麼這個範例重要？

這個 prompt 示範了如何描述視覺效果：

| 你說的 | Claude 理解的 |
|--------|-------------|
| 深色背景 #1a1a2e | 具體的顏色代碼 |
| 圓形頭像佔位 | CSS border-radius: 50% |
| hover 亮光效果 | CSS hover 動畫 |
| 手機版自動調整 | Responsive design |

你不需要知道右邊那些技術名詞。你只要用「人話」描述你想要的效果，Claude 會翻譯成技術語言。

## 如何保存你的作品

Artifacts 的作品會隨著對話存在。如果你想長期保留：

1. **截圖**：最簡單，按 `Cmd + Shift + 4`（Mac）或 `Win + Shift + S`（Windows）
2. **複製程式碼**：點擊 Artifacts 面板上的「Copy」按鈕，把 HTML 原始碼存到你的筆記裡
3. **下載**：有些 Artifacts 支援直接下載成 HTML 檔案
