# 7.4 MVP 實戰 B：團隊午餐決定器

一個比「轉盤」更實用的版本。

## 需求

辦公室裡每天最痛苦的決定：中午要吃什麼？這個工具要幫團隊解決這個千古難題。

## Prompt

> 「請用 React Artifacts 做一個『團隊午餐決定器』。
>
> 功能：
> 1. 可以新增餐廳名單（輸入框 + 新增按鈕）
> 2. 每個餐廳可以標記標籤（日式、中式、西式、便當、速食）
> 3. 有篩選功能：可以勾選「今天不想吃什麼」來排除
> 4. 一個大大的『幫我決定！』按鈕
> 5. 按下去後，用動畫效果（像老虎機一樣滾動）選出一家餐廳
> 6. 選出來後，顯示餐廳名稱 + 一句搞笑的「今日推薦理由」
>
> 設計：
> - 溫暖的配色（奶油白 + 橘色系）
> - 食物相關的 emoji 裝飾
> - 標題：『不要再問了，就吃這家！』
> - 響應式，可以用手機開」

## 為什麼這個比轉盤好？

- 可以**新增餐廳**（不是寫死的選項）
- 可以**篩選排除**（「今天不想吃日式」）
- 有**動畫效果**（增加儀式感）
- 有**搞笑推薦理由**（增加娛樂性）

## 迭代方向

如果你想讓它更有「商業價值」：

> 「再加一個功能：記錄最近 7 天吃過的餐廳，避免連續選到同一家。用列表顯示在最下方。」

這個小功能讓它從「好玩的玩具」進化成「真的實用的工具」。
