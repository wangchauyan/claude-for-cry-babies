> *「你已經從『我做不到』畢業成『我還沒做過』。這兩句話差很多。」*

---

這本書教你用 Claude 來做東西。但 Claude 只是一個不斷擴張的宇宙中的一個工具。以下是四個你可以帶著你的建造者心態前進的方向，取決於什麼讓你最興奮。

---

## 方向 1：學一點基礎 HTML/CSS（概念層）

你已經在不知不覺中接觸了 HTML 和 CSS —— Claude 做的每一個 Artifact 都在用它們。只要學會*概念*（不用背語法），就能讓你在描述需求時精準度大幅提升。

**該學什麼（以及現在先跳過什麼）：**

| 學這些 | 先跳過這些 |
|--------|----------|
| HTML 標籤是什麼（標題、段落、div、按鈕） | 背誦所有 HTML 標籤 |
| CSS 屬性怎麼運作（顏色、字型大小、margin、flexbox） | CSS grid、動畫、預處理器 |
| 元素在頁面上的排版方式（box model） | 響應式斷點和 media query |
| JavaScript 如何處理事件（點擊、輸入、變更） | JavaScript 框架（React、Vue、Angular） |

**推薦資源：** [freeCodeCamp](https://www.freecodecamp.org/) —— 免費、自訂進度、專為完全初學者設計。「Responsive Web Design」認證大約 2-3 週（一天一小時）就能學完以上所有內容。

**既然 Claude 會幫你寫程式碼，為什麼還要自己學？** 因為理解 Claude 在做什麼，能讓你給出更好的指令。這就像你在跟大廚說菜該怎麼做的時候，知道「saut」是什麼意思。你不需要自己炒，但懂那些詞彙會讓你的指令精準 10 倍。

---

## 方向 2：探索 No-Code / AI-Code 工具生態

如果你想超越單頁的 Artifacts，做更複雜的應用程式，有一個正在壯大的工具生態系，專門為像你這樣的人設計：

| 工具 | 做什麼 | 難度 | 最適合 |
|------|--------|------|--------|
| **Cursor** | AI 驅動的程式碼編輯器 —— 用描述的方式寫 App | 中等 | 用 AI 輔助做完整的應用程式 |
| **Bolt.new** | 一句話生成並部署完整的網站 App | 簡單-中等 | 快速的全端原型 |
| **Replit** | 在瀏覽器裡寫程式 + 部署，有 AI 輔助 | 簡單-中等 | 帶輔助輪學程式 |
| **Lovable** | 專注於做出好看、可部署的 App 的 AI 建構器 | 簡單 | 非開發者想要有品質的成品 |
| **Bubble** | 視覺化的 App 建構器，有資料庫，不用寫程式 | 中等 | 有用戶帳號和資料的複雜 App |
| **Zapier / Make** | 用自動化工作流串接不同的應用服務 | 簡單 | 在不同服務之間自動化重複性任務 |

**這些跟你學過的東西有什麼關係：**

| 你在這本書裡學到的 | 下一步去哪裡 |
|------------------|------------|
| 用白話文描述 UI | Bolt.new、Lovable —— 同樣的技能，更大的產出 |
| 做單頁 Artifacts | Cursor、Replit —— 同樣的概念，多頁 App |
| 綠野仙蹤 MVP | Zapier —— 把手動的步驟自動化 |
| 迭代式 Prompting | 所有的 AI 程式碼工具都用同樣的模式 |

你在這裡學到的技能可以直接轉移。你用任何這些工具都不是從零開始。

## 方向 3：用 AI 接案賺錢

大多數人還沒意識到一件事：**「能幫別人做 AI 驅動工具的人」是一門可以賺錢的生意。**

小公司、獨立創業者、以及大公司裡的各個部門，都有一些問題可以用簡單的工具解決 —— 但他們不知道怎麼做。你知道。

**Freelance AI 工具建構長什麼樣子：**

| 服務 | 你會做什麼 | 大概的行情 |
|------|----------|----------|
| 客製儀表板 | 做一個視覺化工具來追蹤他們特定的指標 | $200-500 |
| 內容工作流 | 為他們的內容創作建立模板和 prompt | $100-300 |
| 報告自動化 | 做一個工具來產生他們週期性的報告 | $300-800 |
| 內部工具 | 做一個簡單的計算機、轉換器或追蹤器給團隊用 | $150-400 |
| Prompt 套件 | 為他們的使用場景開發一組最佳化的 prompt | $200-500 |

**去哪裡找客戶：**
- 從你已經認識的人開始（朋友的公司、附近的店家、你自己的公司）
- Freelance 平台（Upwork、Fiverr —— 搜尋「AI automation」看看需求有多大）
- LinkedIn（發文分享你在做的東西 —— 有興趣的人會來找你）

你不需要自稱工程師。「我幫公司做客製化的 AI 驅動工具」是一個完全合理的自我介紹。

## 方向 4：了解不同 AI 模型和它們的強項

Claude 很厲害，但它是一個正在擴張的領域中的一個選手。理解整個版圖能幫助你為每個任務選擇最對的工具：

| AI 工具 | 強項 | 最適合 |
|---------|------|--------|
| **Claude** (Anthropic) | 長文件、細膩的文筆、Artifacts、審慎推理 | 做工具、寫作、分析、創意工作 |
| **ChatGPT** (OpenAI) | 廣泛的知識、外掛生態系、圖片生成（DALL-E） | 通用協助、視覺內容、大量外掛整合 |
| **Gemini** (Google) | Google 生態系整合、多模態（文字 + 圖片 + 影片） | 在 Google Workspace 裡工作、分析視覺內容 |
| **Perplexity** | 即時網路搜尋 + 附來源引用 | 研究、事實查核、掌握最新資訊 |

**聰明的做法：** 先精通一個工具（你已經用 Claude 做到了），然後學會什麼時候該用其他的。你不需要成為每一個工具的專家 —— 只要知道在不同情境下該拿哪一個就好。

## 共同的脈絡

注意到這四個方向的共通點了嗎：**它們都建立在你已經有的技能之上。**

你不是從頭開始。你沒有丟掉你學過的東西。你是在延伸它。每一個方向都用到清晰溝通、迭代思維、以及你在這本書裡培養出來的建造者心態。

你選哪條路，取決於什麼讓你興奮。沒有錯的答案。唯一錯的選擇是什麼都不選，讓這些技能生鏽。
