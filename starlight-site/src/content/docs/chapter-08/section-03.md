> *「知識不是力量。知識被持續應用一段時間才是力量。只用過一次然後就忘了的知識，叫做你凌晨兩點看過的 YouTube 影片。」*

---

學完這本書不代表你「畢業」了。這本書裡的技巧會過時。Claude 會改版。新功能會出現。我們教的某些東西，一年後可能會完全不同。

但只要你養成以下三個習慣，不管外面怎麼變，你都能一直保持領先。把它們當成你的「成長作業系統」。

---

## 習慣 1：每週做一個小工具

不用是大工具。不用是創業等級的產品。不用是多了不起的東西。就是每週一個小小的、有用的東西。

**為什麼有效：** 重複練習才能建立流暢度。你不會學一門語言的方法是讀六個月文法然後才開口說話。你是靠著不斷地說、說得很爛、然後每次好一點點來學會的。

**每週構建規則：**
- 時間限制：最多 1 小時
- 範圍：一個功能、一個畫面、一個目的
- 必做：至少真的用它一次
- 加分：分享給別人看

**需要靈感？這裡有一份入門清單：**

| 週次 | 做這個 | 你會練到什麼 |
|------|-------|------------|
| 1 | 會議議程產生器 | 文字格式化、模板設計 |
| 2 | 簡報用的配色選擇器 | 視覺化 Artifacts、CSS |
| 3 | 記帳分類器（貼上收據，自動分類） | 資料處理 |
| 4 | Email 標題 A/B 測試器 | 內容生成、比較 UI |
| 5 | 生日提醒儀表板 | 資料展示、日期處理 |
| 6 | 你那個產業的縮寫字解碼器 | 參考工具、搜尋功能 |
| 7 | 「這封信該不該寄？」語氣檢查器 | 文字分析、回饋 UI |
| 8 | 團隊 Standup 模板產生器 | 表單、結構化輸出 |
| 9 | 簡易番茄鐘計時器（附任務筆記） | 互動式 JavaScript、計時器 |
| 10 | 個人 CRM（追蹤該聯絡誰） | 資料管理、表格 |
| 11 | 讀書筆記整理器 | 內容輸入、分類 |
| 12 | 年度回顧資料視覺化 | 圖表、資料敘事 |

12 週之後，你做了 12 個東西。你的信心和速度會跟今天判若兩人。

## 習慣 2：建立你自己的 Prompt Library

每次你寫了一個好用的 prompt，把它存起來。不要讓它消失在對話紀錄裡。找個地方有系統地整理它。

**怎麼分類你的 Prompt Library：**

| 類別 | 放什麼 | 範例 |
|------|--------|------|
| **文案類** | Email 模板、報告格式、內容產生器 | 「寫一封專案更新 Email，要包含⋯⋯」 |
| **分析類** | 資料處理、摘要、比較 prompt | 「分析這份試算表，找出⋯⋯」 |
| **設計類** | Artifacts 建構 prompt、UI 描述、工具規格 | 「做一個互動工具，功能是⋯⋯」 |
| **Debug 類** | 修復 prompt、錯誤處理模板、重建 prompt | 「這個 Artifacts 有以下錯誤⋯⋯」 |
| **學習類** | 概念解釋、學習計畫、練習題產生器 | 「用五歲小孩聽得懂的方式解釋⋯⋯」 |
| **工作專用** | 針對你的工作、產業或團隊的客製 prompt | 任何能讓你獨特的工作更輕鬆的東西 |

**放在哪裡：**
- 一個簡單的 Google Doc 或 Notion 頁面就很夠了
- 或者在 Claude 裡建一個叫「我的 Prompt Library」的 Project，把最佳 prompt 放在 Custom Instructions 裡
- 甚至一本實體筆記本也行，如果你是老派的人（致敬）

**關鍵習慣：** 每次你寫了一個 prompt 得到很棒的結果，就複製到你的 library 裡。附一個小註記說明為什麼它有效。久而久之，你會擁有一份比任何通用 prompt 指南都更有價值的**個人化秘笈**。

## 習慣 3：關注 AI 更新（每月 30 分鐘）

AI 變化很快，但你不需要走火入魔。你只需要保持知道就好。

**每月 30 分鐘例行公事：**

| 時間 | 做什麼 | 在哪裡 |
|------|-------|-------|
| **10 分鐘** | 瀏覽 Anthropic 的 Blog 看 Claude 更新 | [anthropic.com/blog](https://anthropic.com/blog) |
| **10 分鐘** | 逛一下 AI 社群看有趣的使用案例 | Reddit r/ClaudeAI、Twitter/X #ClaudeAI、相關論壇 |
| **10 分鐘** | 試用一個你還沒用過的新功能 | Claude.ai —— 直接實驗 |

**在更新裡找什麼：**
- 新功能或新能力（Claude 定期都有更新）
- 現有功能的改進（你已經在用的東西可能變更好了）
- 新的模型版本（Claude 4、Claude 5⋯⋯每個版本都更聰明）
- 社群發現（其他使用者常常找到你想都想不到的創意用法）

**不要做的事：**
- 不要試著看完所有東西。掃過標題，挑 1-2 個有趣的深入看就好。
- 如果你跳過了一個月，不用覺得落後。你學的基礎會撐住你。
- 不要追逐每一個新 AI 工具。先精通一個（Claude），再考慮其他的。
- 不要為了焦慮而刷 AI 新聞。30 分鐘，然後關掉分頁。

## 複利效應

當你同時執行這三個習慣，會發生什麼事：

```
第 1 個月：你做了 4 個小工具。存了 5 個好 prompt。知道了一個新功能。
第 3 個月：你做了 12 個工具。你有 15+ 個 prompt。你發現了 Projects。
第 6 個月：你做了 24 個工具。你的 prompt library 變成你的秘密武器。
          同事開始問「你那個是怎麼做的？」
第 12 個月：你做了 50+ 個工具。你是團隊裡的 AI 解決方案擔當。
           你在教別人。你的職涯軌跡已經轉向了。
```

那些每週的單次練習，每一次都感覺沒什麼了不起。但累積一年之後呢？你已經打造了一套真正稀有且有價值的技能組合。

最好的開始時間是昨天。第二好的是這個禮拜。
