> *「我以前花兩小時做樞紐分析表。現在上傳檔案然後說『有什麼有趣的？』我可能正在讓自己失業。」*

---

## 怎麼上傳？

超級簡單，簡單到有點丟臉：

1. 打開 **claude.ai**
2. 看到打字的輸入框了嗎？
3. 旁邊有個**迴紋針圖示**（📎）或「+」按鈕？點它。
4. 選擇你電腦裡的檔案
5. 問你的問題

就這樣。不需要特殊格式、不需要「資料匯入精靈」、不需要「請確認您的欄位已正確分隔」。拖、放、問。

**支援格式**：`.xlsx`、`.xls`、`.csv`、`.tsv`——基本上任何長得像試算表的東西。

---

## 完整實戰：分析銷售數據

假設你是一個區域業務經理，手上有一份半年的銷售數據 CSV。以下是一段有生產力的對話長什麼樣。

### 第一回合：先看全貌

上傳你的檔案然後說：

```
我上傳了我們 1 月到 6 月的銷售數據。
請幫我分析，告訴我：

1. 整體趨勢：銷售是上升、下降、還是持平？
2. 依總營收排名的前 5 個產品
3. 任何看起來異常或意外的數據點
4. 哪個月最強、哪個月最弱，以及你根據數據
   推測的可能原因
5. 一段 Executive Summary（一個段落），
   讓我可以直接貼到寫給 VP 的 Email 裡
```

**Claude 會做什麼**：它會讀完整份檔案、理解欄位結構、進行分析，然後給你一個包含五個要點的結構化回覆。Executive Summary 會是專業的、可以直接寄出的語言。

### 第二回合：挖深一層

在同一個對話裡接著問：

```
分析得不錯。現在我們挖深一點：

1. 依地區拆分銷售數據。哪個區域成長最快？
2. 有沒有正在衰退的產品？我們該擔心嗎？
3. 過去六個月的平均客單價趨勢如何？
4. 如果趨勢持續，你預估 Q3 會怎樣？
```

**Claude 會做什麼**：更深入的分析，包括趨勢預測。它沒有水晶球，但它會給你基於數據的推測，並標記風險。

### 第三回合：變成可執行的

```
根據你到目前為止發現的所有東西，給我：

1. 三個我應該帶到下次 team meeting 的具體行動項目
2. 一個最能在簡報中產生衝擊力的圖表建議
3. 一個「辣評」——這份數據裡大部分人會漏掉的一件事
```

**看到發生什麼事了嗎？** 三個回合、十五分鐘。你從「我有一個試算表」變成「我有分析結果、行動項目、和簡報角度」。請一個數據分析師做同樣的事，他會跟你收一天的工時。

## 進階招：請它生成 Excel 公式

這招會讓人下巴掉下來。Claude 分析完你的數據之後，問它：

```
太棒了。現在我想自己在原始 Excel 裡做一些分析。
能不能給我需要的 Excel 公式：

1. 計算每月銷售的滾動平均值
2. 找出每個區域的 Top 產品
3. 做一個條件格式化規則，把月成長率 >20% 的標亮
4. 建一個 VLOOKUP（或 XLOOKUP）從參照表
   拉產品名稱

用我檔案裡的*實際欄位名稱*來寫公式，
然後告訴我每個公式要貼在哪裡。
```

**Claude 會做什麼**：用你*實際*的欄位名稱生成可以直接貼上的 Excel 公式（因為它讀過你的檔案，它知道欄位叫什麼）。這就像有一個已經看過你數據的 Excel 家教。

## 重要注意事項

### 檔案大小限制

Claude 有上傳檔案的大小限制。目前大概是：

| 方案 | 大約限制 |
|------|---------|
| Free | 約 10 MB 每個檔案 |
| Pro | 約 30 MB 每個檔案 |
| Team/Enterprise | 約 30 MB 每個檔案 |

如果你的檔案太大，試試：
- 篩選到你只需要的列和欄
- 存成 CSV（比 XLSX 小）
- 拆成多個檔案分別上傳

### 敏感資料警告

**上傳之前先想一下。** Claude 在 Anthropic 的伺服器上處理你的檔案。如果你的試算表包含：

- 客戶個資（姓名、Email、電話）
- 包含帳號的財務紀錄
- 醫療數據（受 HIPAA 保護的資訊）
- 商業機密或專利配方

⋯⋯你應該先看看公司的資料政策。有些組織對什麼東西可以跟 AI 工具共享有明確的規定。不確定的話，問你的 IT 或法務部門。或者在上傳前先去識別化（把真實姓名換成「客戶 A、B、C」之類的）。

### 資料品質很重要

Claude 很聰明，但它是用你給它的東西來分析的。**垃圾進、垃圾出**這個原則永遠適用：

| 問題 | 會怎樣 | 怎麼修 |
|------|--------|--------|
| 欄位沒有名稱 | Claude 猜每一欄代表什麼 | 上傳前加上清楚的欄位標題 |
| 資料類型混亂 | 數字存成文字會搞混分析 | 先在 Excel 裡整理格式 |
| 空值太多 | 分析可能失準 | 填空值，或跟 Claude 說「有些值遺漏了，請適當處理」 |
| 合併儲存格 | Claude 可能讀錯結構 | 取消合併，用正規的列跟欄 |
| 多個工作表 | Claude 可能只讀第一個 | 指定要分析哪個工作表，或分別上傳 |

### Pro Tip：告訴 Claude 你的資料背景

加一行簡短的說明差別就很大：

```
差的：（上傳檔案）「分析這個」

好的：（上傳檔案）「這是我們 2025 Q2 的銷售數據。
每一行是一筆交易。欄位有：日期、產品名稱、
區域、業務、營收、銷售數量。
請分析依區域和產品類別的趨勢。」
```

你給的背景越多，分析就越到位。Claude 可以自己猜出欄位的意思，但你何必讓它猜呢？直接告訴它不是更快嗎？
