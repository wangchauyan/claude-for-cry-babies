> *「Claude 寫了程式。Claude 跑了程式。Claude 給我看了一張圖表。我在旁邊吃三明治。這就是未來。」*

---

## 這是什麼？

概念很簡單：Claude 不只能*寫*程式——它還能直接**執行**。就在對話裡。不用設定、不用安裝、不用終端機、不用什麼「開發環境」。Claude 寫一段 Python 腳本，在安全的雲端沙盒裡執行，然後把結果秀給你。

對你這個非開發者來說，這代表什麼？代表你不需要在自己的電腦上安裝任何東西。**專業等級的數據分析、圖表、檔案處理——不用懂任何一行程式碼。**

把它想成一個坐在你旁邊的數據科學家，只不過：
- 他幾秒鐘就做完，不是幾小時
- 他從來不會說「你可以先把需求文件寄給我嗎？」
- 他不需要咖啡休息時間（但你需要——照顧好自己）

---

## 什麼時候需要 Code Execution？

大部分時候，Claude 的一般文字分析就夠用了。但有些情況你需要出動重武器：

| 情境 | 為什麼一般分析不夠 | Code Execution 怎麼解決 |
|------|-------------------|----------------------|
| **大數據集**（1000+ 行） | 純文字分析可能漏掉大數據中的模式 | Python 可以每一行都算過去 |
| **精確計算** | 複雜公式的心算偶爾會出錯 | 程式碼保證數學精確性 |
| **發表等級的圖表** | Artifacts 的圖表不錯但不一定夠精美 | Matplotlib/Seaborn 能做出簡報等級的視覺效果 |
| **檔案轉換** | 合併或重塑資料需要真正的處理 | Pandas 可以合併、樞紐分析、篩選、轉換 |
| **統計分析** | 相關性、迴歸、顯著性檢定 | SciPy 和 NumPy 做真正的統計 |
| **檔案輸出** | 你需要一個新的 CSV、Excel 檔或圖片檔 | 程式碼可以生成可下載的檔案 |

## 完整範例：從 CSV 到洞察到圖表

一個真實的工作流程。你有一份網站流量數據的 CSV。

### Step 1：上傳和探索

上傳你的 CSV 然後說：

```
我上傳了過去一年的網站流量數據。
請用 Code Execution 幫我：

1. 載入資料，顯示前幾行讓我確認看起來是對的
2. 給我基本統計：
   - 總共幾行幾欄
   - 涵蓋的日期範圍
   - 有沒有缺失值
3. 顯示關鍵數值欄位的統計摘要
   （平均、中位數、最小、最大）
```

**會發生什麼**：Claude 用 Pandas 寫了一段 Python 腳本、執行它、然後秀給你結果——一個乾淨的數據預覽加上統計資訊。你沒有安裝 Python。你沒有寫 `import pandas as pd`。Claude 全包了。

### Step 2：分析趨勢

```
資料看起來沒問題。現在請：

1. 計算每月平均的頁面瀏覽數和獨立訪客數
2. 找出被瀏覽最多的前 10 個頁面
3. 找出一週中哪一天流量最高
4. 檢查社群媒體推薦流量和頁面瀏覽數之間
   有沒有相關性
5. 做一張折線圖，顯示每月流量趨勢，
   同時包含頁面瀏覽數和獨立訪客數
```

**會發生什麼**：Claude 寫更多程式碼、跑分析、然後生成圖表。圖表直接以圖片的形式出現在對話中，你可以下載。

### Step 3：拿到成品

```
這正是我需要的。能不能：

1. 把每月摘要存成一個新的 CSV 檔讓我下載
2. 做一個精美版的流量趨勢圖表
   （更大、有標題、軸標籤、圖例）
   讓我可以放到簡報裡
3. 做一張「流量成績單」的圖片，把關鍵數據
   用視覺化好看的方式呈現
```

**會發生什麼**：Claude 生成可下載的檔案。你點一下下載 CSV。再點一下下載圖表圖片。貼到你的簡報裡。完工。

## Code Execution 實際上長什麼樣？

Claude 使用 Code Execution 的時候，你會看到：

1. **一段程式碼區塊** — Claude 秀出它要執行的程式碼（不用擔心看不看得懂，放在那裡是為了透明）
2. **「分析中」的指示器** — Claude 在安全的沙盒中執行程式碼
3. **輸出結果** — 文字結果、表格、圖表、或可下載的檔案出現在對話中
4. **如果有錯誤** — Claude 會看到錯誤訊息、自己修正、然後自動重試

你不需要做任何事。看著等就好。通常幾秒鐘就搞定。

## 重要注意事項

### 需要 Claude Pro（或更高）

Code Execution（也叫「分析」模式）在 Claude 的 **Pro 方案**以上才有。如果你是免費版，你不會看到這個功能。但說真的，如果你這本書已經讀到這裡，Pro 對你來說大概是值得的。

### 隔離的執行環境

每次 Code Execution 都在一個全新的、隔離的沙盒中執行。這代表：

- 它**不能上網**（不能即時抓取資料）
- 它**不能存取你的電腦**（完全沙盒化）
- 一個 session 的檔案**不會**保留到下一個
- 如果你開新對話，需要重新上傳檔案

### 時間限制

Code Execution 有時間限制（通常每次執行約 60 秒）。如果你的分析跑太久——比如你在處理一個超大的數據集——Claude 會：
- 優化程式碼讓它跑更快
- 拆成更小的區塊
- 告訴你這個任務對這個環境來說太大了

### 有哪些工具庫可用？

Claude 的沙盒預裝了常用的 Python 工具庫：

| 工具庫 | 做什麼的 | 你為什麼會用到 |
|--------|---------|--------------|
| **Pandas** | 數據處理 | 讀取、篩選、合併試算表 |
| **NumPy** | 數學和統計 | 複雜計算 |
| **Matplotlib** | 圖表和圖形 | 產出視覺化結果 |
| **Seaborn** | 漂亮的圖表 | 更漂亮的圖表 |
| **SciPy** | 進階統計 | 迴歸、相關性、統計檢定 |
| **Pillow** | 圖片處理 | 製作或修改圖片 |

你不需要知道這些名字。只要描述你要什麼，Claude 會自己挑對的工具。

## 什麼時候用 Code Execution vs Artifacts？

| | Code Execution | Artifacts |
|---|---|---|
| **適合** | 處理資料、跑統計、生成圖表檔案 | 做互動式工具和網頁 |
| **輸出** | 圖片、檔案、計算結果 | 可互動的網頁元件 |
| **資料來源** | 你上傳的檔案 | 你在對話中提供的資料 |
| **典型用途** | 「分析這份 CSV 然後畫圖」 | 「做一個計算機讓我用」 |
