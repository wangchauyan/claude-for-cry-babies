---


## 這是什麼？

Claude 可以在對話中直接**執行 Python 程式碼**。

對非開發者來說，這代表什麼？代表你不需要在自己的電腦上安裝任何東西。Claude 在雲端幫你跑程式，你只要看結果就好。

## 什麼時候需要它？

通常你只是上傳檔案 + 問問題，Claude 就能回答。但以下情況，Code Execution 會特別有用：

- **數據量很大**：超過 1000 行的 CSV，需要計算統計值
- **需要精確計算**：Claude 的「心算」偶爾會出錯，但跑 Python 不會
- **需要生成圖表**：用 matplotlib 或 plotly 畫的圖比 Artifacts 裡的更專業
- **需要合併多份檔案**：把三個 Excel 合成一個

## 實戰：上傳 CSV → 自動分析 → 輸出圖表

> 「（上傳 monthly_sales.csv）
>
> 請用 Python 幫我：
> 1. 讀取這份 CSV
> 2. 計算每月的平均營收和成長率
> 3. 找出營收最高和最低的月份
> 4. 畫一張折線圖（X 軸是月份，Y 軸是營收）
> 5. 在圖上標註最高和最低點
>
> 執行完後請讓我下載結果圖表。」

Claude 會：
1. 自動寫一段 Python 程式碼
2. 在雲端執行它
3. 把結果圖表顯示給你
4. 你可以下載圖片

整個過程，你不需要懂任何一行程式碼。

## 注意事項

- Code Execution 需要 Claude Pro（付費版）
- 執行環境是隔離的，不會影響你的電腦
- 每次執行有時間限制，太複雜的計算可能會超時
