> *「我的 VP 要我明天早上交季度報告。我午餐前就做完了。她以為我請了一個實習生。某種意義上我確實請了。」*

---

這一節把前面學到的所有技能串在一起。我們要走一遍一個完整的真實場景：一個行銷 PM 需要在明天之前準備好季度報告，要用到多種檔案類型和本章所有的技巧。

這就是 Claude 從一個「工具」變成一套「工作流程」的時刻。

---

## 情境

**你是**：一家中型企業的行銷 PM。
**任務**：你的 VP 要你在明天早上 10 點的主管會議上做一場季度行銷回顧簡報。
**你手上有的**：
- 一份 Excel：各管道的行銷花費明細
- 一份 CSV：Google Analytics 的網站流量數據
- 一張截圖：Google Ads 後台的廣告表現
- 一份上週開始寫到一半就放棄的大綱

**你需要的**：
- 關鍵的洞察和趨勢
- 搭配的圖表
- Executive Summary / 開場白
- Q&A 的應對準備

**時間**：現在下午三點。開工。

---

## Step 1：分析 Excel（行銷花費）

上傳 Excel 檔：

```
我正在準備明天主管會議的季度行銷報告。
這份 Excel 是我們 Q3 2025 的各管道行銷花費
（七月、八月、九月）。

請分析：
1. 各管道和各月份的總花費
2. 哪個管道投入最多？
3. 月環比的變化：有沒有哪個管道花費正在增加或減少？
4. 如果有轉換或 lead 的數據，計算成本效率
5. 標記任何看起來異常或值得特別提出的地方

分析要精簡——我要把這些轉成簡報的投影片。
```

**你會得到**：花費模式、趨勢和重點數據的結構化拆解。把重要發現記下來（或複製到筆記裡）。

---

## Step 2：分析 CSV（網站流量）

上傳 Google Analytics 的 CSV：

```
同一份季度報告。這份 CSV 是 Q3 2025 的
Google Analytics 網站流量數據。

請分析：
1. 每月獨立訪客和頁面瀏覽數的趨勢
2. 流量來源排名（自然搜尋、付費、社群、直接、推薦）
3. 哪個來源跟上一季比成長最多
   （如果能從趨勢推斷的話）？
4. 跳出率趨勢——訪客有在互動還是馬上走？
5. 流量高峰有沒有跟特定日期對應
   （可能是活動帶來的效果）？

另外，請用 Code Execution 做兩張圖表：
- 一張堆疊長條圖，顯示各月份的流量來源分佈
- 一張折線圖，顯示本季跳出率的趨勢

兩張圖表都要簡報等級：大字、清楚的標籤、
專業的配色。
```

**你會得到**：流量分析加兩張可下載的圖表，可以直接丟到投影片裡。

---

## Step 3：解讀截圖（Google Ads Dashboard）

上傳 Google Ads 的 Dashboard 截圖：

```
同一份報告。這是我們 Q3 2025 Google Ads
後台的截圖。

請幫我：
1. 讀取所有可見的指標並摘要
2. 我們的廣告花費效率怎麼樣
   （CPC、CPA、ROAS 如果看得到的話）？
3. 哪些廣告活動表現最好和最差？
4. 把這邊看到的跟 Step 1 的行銷花費數據做交叉比對
   ——廣告表現有合理化那些花費嗎？
5. 有沒有什麼紅旗，我應該在會議上
   被問到之前先主動處理？
```

**你會得到**：交叉引用的洞察。Claude 記得 Step 1 的花費數據（因為是同一個對話），然後把這些點連起來。這種跨檔案的分析超級強大，手動做的話要花你好幾個小時。

---

## Step 4：整合成簡報

壓軸的時候到了：

```
完美。你現在手上有三個資料來源的數據了。
讓我們來做簡報：

1. 簡報大綱
   做一個逐頁的大綱（8-10 頁），適合 15 分鐘的
   季度行銷回顧。每頁要放什麼內容都寫出來。

2. 開場白
   寫一段 2 分鐘的開場白讓我可以直接念。
   要命中重點、有自信但也坦承挑戰。
   要像資深行銷主管在講話，不是在唸報告。

3. 關鍵視覺化
   列出最重要的 4-5 張圖表/視覺化，
   能做的就用 Artifacts 或 Code Execution 做出來。

4. EXECUTIVE SUMMARY
   一段話（最多 5 句）概括這一季。
   這段會放在第二張投影片，
   也會放在我寄簡報的那封 Email 裡。

5. Q&A 準備
   預測主管們最可能問的 5 個問題，
   然後幫我準備簡潔、有數據支撐的回答。
   特別準備好這幾個問題：
   - 「為什麼成本上升了？」
   - 「ROI 到底怎麼樣？」
   - 「我們應該砍掉哪個管道？」
```

**你會得到**：一整套簡報套件。大綱、開場白、視覺化、摘要、Q&A 準備。你剛剛從「三份雜亂的檔案加滿滿的焦慮」變成「已經準備好上場了」，整個過程大約一小時。

---

## 同一對話的上下文魔法

注意一件很關鍵的事：**所有東西都在同一個對話裡完成的。** 當你在 Step 4 要求 Claude 整合洞察的時候，它記得：

- Step 1 的行銷花費拆解
- Step 2 的流量分析和圖表
- Step 3 的 Google Ads 解讀

這就是為什麼單一對話的工作流程這麼強大。Claude 隨著你往前走不斷累積上下文。每一步都豐富下一步。到了 Step 4 的時候，Claude 理解你的整個數據版圖，能做出你自己可能都會漏掉的連結。

**Pro tip**：步驟之間不要開新對話。把所有東西留在同一個 thread 裡。

## 週報產生器 v0.4

是時候再升級一次了。你的週報產生器現在可以利用檔案分析：

```
我想幫我的週報產生器加一個新功能。想法是這樣的：

不再手動打我這週完成了什麼，我想：
1. 上傳我 Google Calendar 一週檢視的截圖
2. 上傳我的任務管理工具
   （Todoist / Asana 之類的）已完成項目的截圖

Claude 應該要：
1. 讀取兩張截圖
2. 抽出完成的會議、活動和任務
3. 自動生成週報的「本週完成事項」和
   「進行中項目」區塊
4. 讓我編輯/調整之後再定稿

請幫我寫出每週要用的 prompt。
要可以直接複製貼上就能用的那種。
```

**你會得到**：一套可重複使用的 prompt，把你的截圖變成週報內容。每到星期五，你不用再對著空白的文字框試著想起這週做了什麼——截圖你的行事曆、上傳到 Claude、幾秒鐘就有一份草稿。

### v0.4 工作流程摘要

```
每週五下午 4:30：
1. 截圖 Google Calendar（週檢視）
2. 截圖任務管理工具（已完成的任務）
3. 兩張圖一起上傳到 Claude，配上標準 prompt
4. Claude 抽出完成事項 + 進行中項目
5. 審閱、調整、定稿
6. 貼到 v0.3 的 Artifact 裡排版

總時間：10 分鐘取代 45 分鐘
省下的時間：拿去準時下班
```

## 第四章回顧

| 技能 | 在哪裡學的 | 超能力 |
|------|-----------|--------|
| 分析試算表數據 | 4.1 節 | 任何 CSV 或 Excel 檔案都能秒出洞察 |
| 摘要長文件 | 4.2 節 | 50 頁文件 30 秒讀完 |
| 解讀圖片 | 4.3 節 | 截圖變數據、草圖變原型 |
| 用程式碼做分析 | 4.4 節 | 專業級圖表和可下載的檔案 |
| 全部串在一起 | 4.5 節 | 端到端的工作流程，省下好幾小時 |

**這一章最大的重點**：Claude 不是一個「順便可以讀檔案的聊天機器人」。它是一個「順便可以聊天的檔案分析師」。當你開始上傳你*真正的*工作檔案——你的數據、你的文件、你的截圖——Claude 就從「蠻有趣的」變成「不可或缺的」。

那些曾經淹沒你的檔案？它們現在是你最大的資產。因為你現在有一個能在幾秒鐘內讀完它們、然後告訴你什麼才重要的幫手。
