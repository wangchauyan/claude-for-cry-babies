---
title: "3.6 Artifacts 的限制（必須誠實說）"
---


Artifacts 很強，但它不是萬能的。知道它的限制，你才不會在錯誤的方向上浪費時間。

## ❌ 不能做的事

### 1. 不能存取外部 API
Artifacts 的網頁是在一個「沙盒」裡運行的，不能連到外面的網路。

所以你不能叫它「即時抓取台積電的股價」或「連到 OpenWeather 顯示天氣」。

**替代方案**：你可以把數據手動丟給 Claude，讓它生成靜態圖表。

### 2. 沒有永久儲存
Artifacts 裡的資料不會被「記住」。如果你在一個 To-Do List 裡新增了三筆資料，重新整理頁面後它們就消失了。

**替代方案**：加一個「匯出」按鈕，讓你把資料複製到剪貼簿。

### 3. 複雜度有上限
不要試圖在 Artifacts 裡做一個完整的 ERP 系統。它適合做「小而美」的工具，不適合做「大而全」的系統。

**經驗法則**：如果你的需求用一張 A4 紙描述不完，它可能太複雜了。

### 4. 每次對話的 Artifacts 會「消失」
Artifacts 存在於當前的對話裡。如果你開一個新對話，之前做的東西就不在了（除非你手動把程式碼存起來）。

**最佳做法**：做出滿意的 Artifacts 後，立刻複製程式碼或截圖保存。

## ✅ Artifacts 的最佳使用場景

| 適合 | 不適合 |
|------|--------|
| 原型展示 | 正式上線的網站 |
| 資料視覺化 | 即時數據 Dashboard |
| 小工具（計算機、轉換器） | 需要登入的系統 |
| 教學互動元件 | 需要資料庫的應用 |
| 創意發想的快速驗證 | 需要付款功能的服務 |

把前兩章的純文字模板，變成一個漂亮的互動介面：

> 「請用 React Artifacts 幫我做一個週報填寫介面。

> - 本週完成事項
> - 下週計畫
> - 遇到的困難
> - 需要的支援
>
> **右邊**是即時預覽區，隨著我在左邊輸入，右邊會即時顯示格式化的週報。

> 預覽的格式要像正式的商務週報，有標題、日期、分隔線。
