title: "3.1 什麼是 Artifacts？"
---


## 白話版

Artifacts 就是 Claude 在對話框右邊幫你「變」出來的互動內容。

你說「做一個計算機」，右邊就出現一個真的可以按的計算機。你說「畫一個圓餅圖」，右邊就出現一個漂亮的圓餅圖。不需要安裝任何軟體，不需要知道什麼是伺服器。

## 它支援什麼類型？

| 類型 | 說明 | 適合做什麼 |
|------|------|-----------|
| **HTML 網頁** | 完整的網頁，有互動功能 | 工具、表單、Landing Page |
| **React 元件** | 更複雜的互動介面 | 儀表板、App 原型、小遊戲 |
| **SVG 圖表** | 向量圖形 | Logo、圖示、示意圖 |
| **Mermaid 流程圖** | 用文字描述生成圖表 | 流程圖、組織圖、甘特圖 |
| **Markdown 文件** | 格式化文字 | 報告、文件、README |

## 重要澄清：Artifacts 不是「部署」

Artifacts 生成的東西活在 Claude 的對話裡。它是**預覽**，不是**上線**。

就像建築師做了一個精美的 3D 模型給你看，但你還沒把房子蓋起來。

如果你想把 Artifacts 的作品變成真正的網站，我們會在第 7 章教你怎麼做。但現在，先享受這個「即時預覽」的魔法。

## 它跟「Claude 只給你程式碼」有什麼不同？

| 沒有 Artifacts | 有 Artifacts |
|----------------|-------------|
| Claude 給你一堆 HTML 程式碼 | Claude 直接在右邊顯示網頁 |
| 你需要自己把程式碼存成檔案、用瀏覽器打開 | 你什麼都不用做，直接看到結果 |
| 看不懂程式碼就等於白搭 | 不懂程式碼也能驗證結果對不對 |

這就是為什麼 Artifacts 對非開發者來說是**革命性的功能**。
