title: "1.3 Claude 能幫你做什麼？（具體清單）"
---


讓我們直接看一份清單。不講虛的，只講你明天上班就能用的。

## ✅ Claude 可以做的事

### 文字類
- 寫文案、改文章、翻譯（中英日韓都行）
- 寫 Email、請假信、離職信、道歉信（各種信）
- 把會議錄音稿整理成 Action Items
- 把 50 頁報告濃縮成一頁摘要

### 分析類
- 分析 Excel / CSV 數據，找出趨勢和異常
- 讀 PDF 合約，用白話解釋重點條款
- 看截圖，解讀 Dashboard 上的數字代表什麼

### 創造類
- 做互動網頁、小工具、儀表板（用 Artifacts）
- 畫流程圖、組織圖、甘特圖
- 幫你做一個可以展示的產品原型

### 學習類
- 教你任何你想學的東西（用你聽得懂的方式）
- 幫你出練習題、批改作業
- 把複雜的概念翻譯成「五歲小孩版」

### 程式碼類
- 幫你寫程式碼（然後修好它）
- 解釋別人寫的程式碼在幹嘛
- 幫你寫 Excel 公式、Google Sheets 函數

## ❌ Claude 不能做的事

- **不能幫你自動發 Email** — 但可以幫你寫好，你複製貼上就行
- **不能直接操作你的手機 App** — 它活在瀏覽器裡
- **不能保證 100% 正確** — 你是 PM，它是工程師，你要 review
- **不能存取你的私人資料** — 除非你主動上傳
- **不能即時連網**（除非開啟 Web Search 功能）

## 一個重要的心態

Claude 就像一個超強的工具，但**你才是決策者**。它給你建議，你決定要不要採納。它寫了程式碼，你決定要不要用。

把它當成你最得力的助手，但不要把腦袋完全外包給它。
