## 什麼是記憶功能？

這可能會讓你嚇一跳：Claude 可以**跨對話**記住你的事 — 就算你沒有用 Projects。

記憶（Memory）是一個讓 Claude 自動從你的對話中學習偏好、背景和習慣的功能。你不需要特別設定什麼，它會在你聊天的過程中自動在背景運作。

舉個例子：如果你在三次不同的對話中分別提到你做行銷、偏好輕鬆語氣、討厭用項目符號，Claude 就會自動開始套用這些偏好 — 不用你每次都重新說一遍。

## 記憶 vs Projects：有什麼不同？

很多人搞混，所以來一次講清楚：

| | 記憶 | Projects |
|---|---|---|
| **運作方式** | Claude 從你的對話中自動學習 | 你手動上傳檔案、寫 Custom Instructions |
| **範圍** | 套用在你**所有**的對話 | 只在特定的 Project 裡有效 |
| **記住什麼** | 偏好、關於你的事實、你的習慣 | 你上傳的東西 + 你的指令 |
| **控制** | 可以查看和編輯 Claude 記住的內容 | 你完全掌控 |
| **最適合** | 個人偏好（語氣、格式、背景） | 任務特定情境（公司資料、專案文件） |

**這樣想：**
- **記憶** = Claude 學到你偏好攝氏而非華氏，因為你之前提過
- **Projects** = 你上傳公司的品牌指南，讓 Claude 用你的品牌語調寫作

它們搭在一起會非常強大。記憶處理的是「你是誰」的部分，Projects 處理的是「你在做什麼」的部分。

## 如何查看 Claude 記住了什麼

想知道 Claude 到底記了你什麼？

**試試這個 Prompt：**
> 「你記得我過去對話中的哪些事？」

Claude 會告訴你它知道什麼。你可能會驚訝 — 或者有點毛毛的 — 它記了這麼多。兩種反應都正常。

## 如何編輯或刪除記憶

你有完全的控制權：

- **在設定裡** → 進入 Claude 的設定，找到 Memory 區塊。你可以查看、編輯、或刪除特定的記憶。
- **在對話中** → 直接跟 Claude 說就好：
  - 「請記住我最近換工作了，現在在 [新公司]」
  - 「忘掉我在 [舊公司] 工作的事」
  - 「記住我偏好表格勝過項目符號」

## 當記憶出錯時

記憶不是完美的。Claude 有時會：
- 記住過時的資訊（你換了工作，但它還在講舊東家的事）
- 過度套用某個偏好（你有一次說要輕鬆語氣，結果之後所有東西都像在傳訊息）
- 搞混情境（把工作上的偏好套到私人對話裡）

**修正方式很簡單：** 直接糾正它。「欸，我已經不在那邊工作了，我現在在 [新公司]。」Claude 就會更新記憶。

## 隱私說明

記憶是你的個人帳號專屬的。Claude 對你的記憶不會跟其他用戶共享，而且你可以在設定裡把整個功能關掉，讓每次對話都是全新開始。

如果你在用 Claude 聊敏感話題，不想這些內容被記住，可以使用**無痕對話**（Incognito Conversations） — 這些對話不會貢獻記憶，也不會存在你的聊天紀錄裡。

## 週報產生器 v0.6（升級版）

> 現在你同時了解 Projects 和記憶了，來看看它們合體的威力：
>
> 1. 你的 **Project** 裡放著你的 Job Description、過去的週報範例、和 Custom Instructions
> 2. Claude 的**記憶**知道你的寫作風格、你主管的偏好、還有你喜歡把段落標題加粗
>
> 兩者合在一起，你只要打開週報 Project，輸入「這週做了 A、B、C」，就能拿到一份聽起來像你寫的、格式符合老闆要求、細節程度剛好的報告 — 而你完全不用解釋任何背景。
>
> 這不是 AI 魔法。這是好的工具設定。
