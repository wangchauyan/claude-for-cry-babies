## 什麼是 Projects？

:::tip[免費版用戶的好消息]
Projects 在免費版也能用！你可以建立 Projects、新增 Custom Instructions、上傳參考檔案。主要限制是免費版的總訊息數較少，所以比較複雜的 Project 工作可能會更快碰到每日限制。如果你打算每天認真使用 Projects 來處理工作，Pro 版的體驗會更順暢——但免費版已經足夠讓你體驗完整功能了。
:::

Projects 是 Claude 的「專案空間」功能。你可以：
- 建立多個 Project（比如「工作」「Side Project」「學英文」）
- 在每個 Project 裡上傳參考文件
- 設定 Custom Instructions（告訴 Claude 在這個 Project 裡它是誰、你是誰）
- 在 Project 裡開新對話，Claude 自動帶著這些背景知識

## 如何建立一個 Project？

### Step 1：點擊側邊欄的 「Projects」
在 Claude 的左側選單裡找到 Projects，點擊「New Project」。

### Step 2：命名你的 Project
給它一個清楚的名字，比如「Q2 行銷企劃」或「我的週報助手」。

### Step 3：上傳參考文件
你可以上傳：
- 公司簡介 PDF
- 你的職位描述
- 過去的週報範例
- 品牌指南
- 任何 Claude 需要「知道」的背景資料

### Step 4：設定 Custom Instructions
這是最重要的一步（下一節詳細教）。

### Step 5：開始對話
在這個 Project 裡開新對話，Claude 就會自動帶著你上傳的所有背景知識。

## 實戰：建立「我的工作」Project

> **Project 名稱**：我的工作
>
> **上傳文件**：
> - 公司簡介（PDF）
> - 我的 Job Description（文字或 PDF）
> - 過去三份週報（作為風格範例）
> - 部門組織架構圖（圖片）
>
> **效果**：從此以後，在這個 Project 裡開新對話，你不需要再說「我是 XX 公司的 PM」或「我的週報風格是 OO」。Claude 都已經知道了。

## Projects vs 普通對話

| 項目 | 普通對話 | Projects |
|------|---------|----------|
| 背景知識 | 每次都要重新說明 | 自動帶入 |
| 參考文件 | 每次都要重新上傳 | 永久保存在 Project 裡 |
| 風格一致性 | 每次都可能不一樣 | 透過 Custom Instructions 確保一致 |
| 適合 | 一次性的問題 | 反覆處理同一類任務 |
