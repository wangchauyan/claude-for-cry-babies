---
title: "6.5 搭配 Web Search：讓 Claude 不再活在過去"
---


Claude 的訓練資料有截止日期，所以它不知道「今天台積電的股價」或「昨天的世界盃比分」。

但 Claude 有一個功能可以解決這個問題：**Web Search**。

:::note[所有方案都能用]
Web Search 在**所有方案都可以使用，包括免費版。** 當你問 Claude 關於時事、最新消息、或任何可能在它的訓練資料之後有變化的問題時，它可以搜尋網路並引用來源。你不需要特別啟用什麼——Claude 會自動判斷什麼時候搜尋對你有幫助。你也可以明確要求：「幫我搜尋最新的 [主題]。」
:::

## 什麼時候需要 Web Search？

| 需要 | 不需要 |
|------|--------|
| 今天的新聞 | 什麼是 GDP |
| 最新的產品更新 | Python 的基本語法 |
| 即時股價或匯率 | 如何寫好的 Email |
| 某個事件的最新進展 | 數學公式推導 |

簡單來說：**問「事實」用 Web Search，問「知識」用 Claude 本身。**

## 怎麼開啟？

在對話框裡，你可以直接告訴 Claude：

> 「請搜尋一下最新的資訊，然後回答我的問題。」

或者在輸入框下方找到搜尋相關的開關（介面可能隨版本更新有所變化）。

## 實戰

> 「請幫我搜尋一下最新的 AI 產業動態（過去一週），然後整理成：
> 1. 三個最重要的新聞
> 2. 對非技術人員的白話翻譯
> 3. 這對我的工作可能有什麼影響（我是 PM）」

## 注意事項

- Web Search 的結果品質取決於搜尋引擎，不是 100% 準確
- 搜尋結果會佔用 Token（記住那張桌子的比喻），所以不要叫它搜尋太多東西
- 對於需要深度分析的問題，建議先搜尋事實，再讓 Claude 基於這些事實做分析

## 🔨 週報產生器 v0.6

建立一個專屬的「週報產生器」Project：

> **Project 名稱**：我的週報助手
>
> **上傳文件**：
> - 你的 Job Description
> - 過去三份你寫過的週報（當風格範例）
>
> **Custom Instructions**：
> ```
> 你是我的週報寫作助手。
>
> 關於我：
> - 我是 [你的公司] 的 [你的職位]
> - 我的主管偏好簡潔、重點式的報告
> - 週報要在每週五下午 4 點前完成
>
> 週報格式：
> - 本週完成事項（3-5 點，每點一句話）
> - 下週計畫（3-5 點）
> - 遇到的困難（如果有的話）
> - 需要的支援（如果有的話）
>
> 風格：參考我上傳的過去週報範例，保持一致。
> 語氣：專業但不囉嗦，用主動句，避免被動句。
> ```

從此，每週五你只要打開這個 Project，輸入「這週做了 A、B、C」，就能一鍵產生風格一致的週報。
