### 等等，免費版有這麼多功能？

對 — 這讓很多人很意外。截至 2026 年，免費版包含 Artifacts、Projects、Web Search、Code Execution、記憶功能、連接器、和桌面擴充功能。重點不是功能差異 — 是**用量限制**。免費版的使用者會更快碰到訊息上限，在尖峰時段（美國工作日上午）限制會更緊。

白話版比喻：免費版給你同一間廚房，但你只能煮幾道菜，然後有人會跟你說「等幾個小時再回來。」

### 免費版和 Pro 的真正差別在哪？

三件事：

1. **用量**：Pro 給你大約 5 倍的訊息量。對每天工作都用 Claude 的人來說，這是「用到上午 11 點就沒了」跟「用一整天都沒問題」的差別。

2. **模型選擇**：免費版有 Sonnet 和 Haiku。Pro 還有 **Opus** — Claude 最聰明的模型。在複雜分析、長文件處理、或細膩寫作上，Opus 明顯更好。

3. **Research & Claude Code**：這兩個是 Pro 專屬功能。Research 讓 Claude 幫你做多步驟的深度調查。Claude Code 是終端機版的程式碼助手。如果這兩個對你來說還沒概念，先不用管。

### 什麼時候該升級 Pro？

問你自己：**「我多常覺得 Claude 可以做更多？」**

| 你的回答 | 建議 |
|---|---|
| 「很少 — 現在這樣就夠用了」 | 留在免費版 |
| 「每週都會碰到限制」 | 升級 Pro |
| 「每天都離不開它」 | 立刻升級 Pro |
| 「它就是我的工作流程」 | 考慮 Max |
| 「我整個團隊都需要」 | 升級 Team |
