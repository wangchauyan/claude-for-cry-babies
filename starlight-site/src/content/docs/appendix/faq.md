## Q1：Claude 的回答可以商用嗎？

**A：可以。** 根據 Anthropic 的使用條款，你用 Claude 生成的內容（文字、程式碼、圖表等）的版權歸你所有。你可以將這些內容用於商業目的。

但建議你在正式商用前：
- 檢查內容的正確性（AI 可能產生錯誤）
- 確認沒有無意中侵犯他人的智慧財產權
- 敏感領域（法律、醫療）的內容請專業人士 review

---

## Q2：我的資料上傳到 Claude 安全嗎？

**A：Anthropic 有明確的隱私政策。** 重點包含：
- **Pro / Team 方案**：你的對話內容預設不會被用來訓練 AI
- **Free 方案**：對話可能被用於改善模型（可在設定中關閉）
- 所有資料都有加密傳輸

**建議**：
- 不要上傳包含個人敏感資訊（身分證號、信用卡號）的檔案
- 公司機密資料建議使用 Team 方案，有更高的安全保障
- 詳細政策請參考 Anthropic 官方的隱私條款

---

## Q3：為什麼 Claude 有時候會「拒絕」我的請求？

**A：Claude 有安全護欄。** 它會拒絕產生以下內容：
- 有害或危險的內容
- 未成年人不宜的內容
- 假資訊或誤導性的內容
- 侵犯隱私的內容

如果你的正常請求被拒絕了，通常是因為 Claude 誤判了你的意圖。試著：
- 重新措辭你的請求
- 說明你的使用場景（例如「這是用於教育目的」）
- 把請求拆分成更小的部分

## Q4：Artifacts 的作品可以直接部署成網站嗎？

**A：可以，但需要幾個額外步驟。**

Artifacts 生成的是 HTML / React 程式碼，你可以：

1. **簡單的 HTML 頁面** → 複製程式碼，存成 `index.html`，上傳到 Netlify Drop 一鍵部署
2. **React 元件** → 需要一點額外設定（建立 React 專案、安裝依賴等），但 Claude 可以教你怎麼做
3. **更簡單的方式** → 用 Bolt.new 或 Replit，把 Claude 生成的程式碼貼進去，一鍵部署

詳細教學見 Ch7.7。

## Q5：Claude 跟 ChatGPT 到底差在哪？

**A：各有所長。**

| 面向 | Claude 強項 | ChatGPT 強項 |
|------|-----------|-------------|
| Artifacts（即時預覽） | ★★★★★ | ★★★☆☆ |
| 外掛 / Plugin 生態 | ★★★☆☆ | ★★★★★ |
| 長文理解 | ★★★★★ | ★★★★☆ |
| 圖片生成 | ❌（不支援） | ★★★★★（DALL-E） |
| 語氣自然度 | ★★★★★ | ★★★★☆ |
| 程式碼品質 | ★★★★★ | ★★★★★ |
| 價格 | $20/月 | $20/月 |

**建議**：如果你主要需求是「做互動工具和原型」，Claude 更適合。如果你需要「生成圖片」或「用大量外掛」，ChatGPT 更適合。

## Q6：我的長對話為什麼品質會下降？

**A：Context Window 的限制。** Claude 的「記憶容量」是有限的。對話越長，它能記住的早期內容就越少。

**解決方案**：
- 用 Projects 保存重要的背景資訊（Ch6）
- 複雜任務拆成多個短對話
- 每隔幾輪，重新摘要目前的進度

---

## Q7：Claude 會「記住」我之前的對話嗎？

**A：同一個對話裡會記住。不同對話之間不會。**

- **同一個對話**：Claude 記得前面所有的內容（直到 Context Window 滿了）
- **不同對話**：每個新對話都是從零開始
- **例外**：如果你用 Projects，Custom Instructions 和上傳的文件會在每次新對話自動帶入

---

## Q8：我可以用 Claude 幫我做作業嗎？

**A：技術上可以，但我們不建議這樣用。**

更好的做法是：
- 請 Claude **教你解題思路**，而不是直接給答案
- 用 Claude **出練習題**給你做
- 做完後請 Claude **批改並解釋錯在哪裡**

這樣你真的學到東西，而不是交了一份你不懂的作業。
