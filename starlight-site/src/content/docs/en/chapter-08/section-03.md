## Habit 1: Build One Small Tool Per Week

Not a big tool. Not a startup. Not even something impressive. Just one small, useful thing every week.

**Why this works:** Repetition builds fluency. You wouldn't learn a language by studying grammar for 6 months and then trying to speak. You learn by speaking badly, often, and getting a little better each time.

**The weekly build rule:**
- Time limit: 1 hour max
- Scope: One function, one screen, one purpose
- Must-do: Use it at least once for real
- Bonus: Share it with someone

**Need inspiration? Here's a starter list:**

| Week | Build This | What You'll Practice |
|------|-----------|---------------------|
| 1 | Meeting agenda generator | Text formatting, templates |
| 2 | Color palette picker for a presentation | Visual Artifacts, CSS |
| 3 | Expense categorizer (paste receipts, get categories) | Data processing |
| 4 | Email subject line A/B tester | Content generation, comparison UI |
| 5 | Birthday reminder dashboard | Data display, date handling |
| 6 | Acronym decoder for your industry | Reference tool, search functionality |
| 7 | "Should I send this email?" tone checker | Text analysis, feedback UI |
| 8 | Team standup template generator | Forms, structured output |
| 9 | Simple pomodoro timer with task notes | Interactive JavaScript, timers |
| 10 | Personal CRM (track who you need to follow up with) | Data management, tables |
| 11 | Book notes organizer | Content input, categorization |
| 12 | Year-in-review data visualization | Charts, data storytelling |

After 12 weeks, you'll have built 12 things. Your confidence and speed will be unrecognizable compared to today.

## Habit 2: Build Your Own Prompt Library

Every good prompt you write is an asset. Don't let it disappear into your conversation history. Save it somewhere organized.

**How to organize your Prompt Library:**

| Category | What Goes Here | Example |
|----------|---------------|---------|
| **Writing** | Email templates, report formats, content generators | "Write a project update email that..." |
| **Analysis** | Data processing, summarization, comparison prompts | "Analyze this spreadsheet and find..." |
| **Building** | Artifact creation prompts, UI descriptions, tool specs | "Create an interactive tool that..." |
| **Fixing** | Debug prompts, error resolution templates, recovery prompts | "This Artifact has the following error..." |
| **Learning** | Concept explanations, study guides, practice question generators | "Explain [concept] like I'm 5..." |
| **Work-specific** | Prompts tailored to your job, industry, or team | Whatever makes your unique work easier |

**Where to keep it:**
- A simple Google Doc or Notion page works fine
- Or a Claude Project called "My Prompt Library" with your best prompts in Custom Instructions
- Or even a physical notebook if you're old-school (respect)

**The key habit:** Every time you write a prompt that gets a great result, copy it to your library. Add a note about why it worked. Over time, you'll have a personalized cheat sheet that's more valuable than any generic prompt guide.

## Habit 3: Follow AI Updates (30 Minutes Per Month)

AI is changing fast, but you don't need to be obsessed. You just need to stay aware.

**The monthly 30-minute routine:**

| Time | Activity | Where |
|------|----------|-------|
| **10 min** | Skim the Anthropic blog for Claude updates | [anthropic.com/blog](https://anthropic.com/blog) |
| **10 min** | Browse an AI community for interesting use cases | Reddit r/ClaudeAI, Twitter/X #ClaudeAI, or relevant forums |
| **10 min** | Try one new feature you haven't used before | Claude.ai -- just experiment |

**What to look for in updates:**
- New features or capabilities (Claude gets these regularly)
- Changes to existing features (things you already use might get better)
- New model versions (Claude 4, Claude 5, etc. -- each gets smarter)
- Community discoveries (other users often find creative uses you'd never think of)

**What NOT to do:**
- Don't try to read everything. Skim headlines, deep-dive on 1-2 interesting items.
- Don't feel behind if you miss a month. The basics you've learned will carry you.
- Don't chase every new AI tool. Master one (Claude) before juggling many.
- Don't doom-scroll AI news for anxiety. 30 minutes, then close the tab.

## The Compound Effect

Here's what happens when you combine all three habits:

```
Month 1:  You build 4 small tools. Save 5 good prompts. Learn about one new feature.
Month 3:  You've built 12 tools. You have 15+ prompts. You discovered Projects.
Month 6:  You've built 24 tools. Your prompt library is your secret weapon.
          Your colleagues start asking "how did you make that?"
Month 12: You've built 50+ tools. You're the go-to person for AI solutions.
          You're training others. Your career trajectory has shifted.
```

None of those individual weekly sessions felt like much. But compounded over a year? You've built a genuinely rare and valuable skill set.

The best time to start was yesterday. The second best time is this week.
