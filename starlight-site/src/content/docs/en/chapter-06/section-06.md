## What Is Memory?

Here's something that might surprise you: Claude can remember things about you **across conversations** — even outside of Projects.

Memory is a feature where Claude automatically learns your preferences, context, and patterns from your conversations over time. It's not something you need to set up — it happens in the background as you chat.

For example, if you've told Claude in three different conversations that you work in marketing, prefer casual tone, and hate bullet points — it starts applying those preferences automatically, without you repeating yourself.

## Memory vs. Projects: What's the Difference?

This confuses a lot of people, so let's make it crystal clear:

| | Memory | Projects |
|---|---|---|
| **How it works** | Claude learns from your conversations automatically | You explicitly upload files and write Custom Instructions |
| **Scope** | Applies across ALL your conversations | Only applies within that specific Project |
| **What it remembers** | Preferences, facts about you, patterns | Whatever you upload + your instructions |
| **Control** | You can view and edit what Claude remembers | You control everything directly |
| **Best for** | Personal preferences (tone, format, background) | Task-specific context (your company info, project docs) |

**Think of it this way:**
- **Memory** = Claude learning that you prefer Celsius over Fahrenheit because you've mentioned it before
- **Projects** = You uploading your company's brand guide so Claude writes in your brand voice

They work together beautifully. Memory handles the "who you are" part. Projects handle the "what you're working on" part.

## How to See What Claude Remembers

Want to check what Claude has picked up about you?

**Prompt:**
> "What do you remember about me from our past conversations?"

Claude will tell you what it knows. You might be surprised — or slightly creeped out — by how much it's picked up. Both reactions are normal.

## How to Edit or Delete Memories

You have full control:

- **In Settings** → Go to your Claude settings and find the Memory section. You can view, edit, or delete specific memories.
- **In conversation** → Just tell Claude:
  - "Please remember that I recently switched jobs to [new company]"
  - "Forget that I work at [old company]"
  - "Remember that I prefer tables over bullet points"

## When Memory Gets It Wrong

Memory isn't perfect. Sometimes Claude will:
- Remember outdated information (you changed jobs but it still references the old one)
- Over-apply a preference (you asked for casual tone once and now everything sounds like a text message)
- Mix up contexts (applying work preferences to personal conversations)

**The fix is simple:** Just correct it. "Hey, I don't work there anymore — I'm now at [new place]." Claude will update its memory.

## Privacy Note

Memory is personal to your account. Claude's memories about you aren't shared with other users, and you can disable the feature entirely in Settings if you prefer a fresh start every conversation.

If you're using Claude for sensitive topics and don't want those details persisted, you can use **Incognito Conversations** — these don't contribute to Memory and aren't saved in your chat history.
