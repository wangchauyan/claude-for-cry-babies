## v1.0 的完整 Prompt

這是重頭戲。把整段 Prompt 複製到 Claude 裡：

> **做一個週報產生器的最終版本（v1.0），用 Artifact 呈現。它應該看起來像一個專業的 SaaS 應用程式。以下是完整需求：**
>
> **排版：左右分屏設計**
> - 左側（40% 寬度）：輸入區
> - 右側（60% 寬度）：即時預覽，隨著使用者打字即時更新
>
> **左側 -- 輸入區：**
> 1. **頂部自動生成日期**（本週一到週五的日期範圍）和一個可編輯的「作者」文字欄位
> 2. **四個輸入區塊，每個有標題和多行文字框：**
>    - 「本週完成事項」（提示文字：「這週你搞定了什麼？」）
>    - 「進行中」（提示文字：「目前正在忙什麼？」）
>    - 「困難與挑戰」（提示文字：「有什麼卡住你了嗎？」）
>    - 「下週計畫」（提示文字：「接下來要做什麼？」）
> 3. 每個文字框支援條列 -- 使用者換行時，在預覽中自動變成一個新的項目符號
>
> **右側 -- 即時預覽：**
> - 即時渲染乾淨、格式化的週報
> - 頂部顯示日期範圍和作者
> - 每個區塊有標題和條列內容
> - 專業的字體排印，適當的間距
> - 看起來要像你會驕傲地寄給副總的東西
>
> **底部工具列 -- 四個功能按鈕：**
> 1. **「複製純文字」** -- 複製純文字格式到剪貼簿，顯示「已複製！」確認
> 2. **「複製 Markdown」** -- 複製 Markdown 格式到剪貼簿
> 3. **「下載 HTML」** -- 下載成有樣式的 HTML 檔案，用瀏覽器打開很好看
> 4. **「風格：正式 / 輕鬆」** 切換按鈕：
>    - **正式**：專業語氣、「本週完成事項」、結構化標題、偏襯線字體
>    - **輕鬆**：親切語氣、「這週幹了啥」、輕鬆標題、無襯線字體、稍微多一點顏色
>
> **設計需求：**
> - 專業的 SaaS 美學：乾淨白色背景、淡淡陰影、適當內距
> - 頂部薄薄一條標題列，顯示 App 名稱「WeeklyBot」和低調的版本標記「v1.0」
> - 響應式：桌面和平板都能用
> - 配色：專業的藍灰色系搭配一個按鈕用的強調色
> - 正式/輕鬆風格切換時有平滑的過渡動畫
> - 文字框高度舒適（每個至少 4 行）
>
> 這應該看起來像一個真正的產品，不是一份作業。

## 最終檢查清單

Claude 生成你的 v1.0 之後，逐項驗證每個功能：

| # | 檢查項目 | 怎麼測試 | 通過？ |
|---|---------|---------|--------|
| 1 | **日期自動填入** | 看標題 -- 有沒有顯示本週日期？ | |
| 2 | **作者欄位能用** | 打你的名字，看預覽裡有沒有出現 | |
| 3 | **四個輸入框都能用** | 每個都打點東西，確認預覽有顯示 | |
| 4 | **即時預覽有在更新** | 打字的同時右側有沒有即時更新？ | |
| 5 | **條列項目正常顯示** | 在一個框裡打多行，有沒有變成項目符號？ | |
| 6 | **複製純文字** | 按下去，貼到記事本 -- 是乾淨的純文字嗎？ | |
| 7 | **複製 Markdown** | 按下去，貼到 Markdown 預覽器 -- 格式對嗎？ | |
| 8 | **下載 HTML** | 按下去，用瀏覽器打開下載的檔案 | |
| 9 | **風格切換** | 在正式和輕鬆之間切換 -- 語氣和設計有變嗎？ | |

## 如果有東西不能用

到這裡你應該已經很熟練了。以下是一些常見的修復方式：

**即時預覽沒有在更新？**
> 「即時預覽沒有隨著我打字更新。可以讓文字框用 onChange 事件，讓每次按鍵都更新預覽嗎？」

**複製按鈕沒有用？**
> 「『複製純文字』按鈕好像沒有複製任何東西到剪貼簿。可以用 navigator.clipboard API，然後加一個『已複製！』的視覺確認，顯示 2 秒嗎？」

**風格切換沒有改語氣？**
> 「正式/輕鬆切換改了字體，但沒有改預覽裡的標題和文字風格。輕鬆模式裡，把『本週完成事項』改成『這週幹了啥』、『進行中』改成『還在煮的菜』、『困難與挑戰』改成『讓我嘆氣的事』、『下週計畫』改成『作戰計畫』。」

## 分享你的作品

做出了一個酷東西，當然要讓別人看到。一個工具躺在你的螢幕上沒人能看到，就像畫了一幅傑作然後把它面對牆壁放。

以下是四種分享方式，從最簡單到最「專業」：

### 方法 1：截圖 / 螢幕錄影

**成本**：最低 | **震撼度**：中低

對 Artifact 截圖（Mac 用 `Cmd + Shift + 4`，Windows 用 `Win + Shift + S`），或者錄一段操作示範影片（Mac 用 `Cmd + Shift + 5`）。記得控制在 60 秒內。

**適合**：在 Line 群組、Slack 頻道裡快速炫耀。發 LinkedIn 貼文。傳給你媽證明你在做正經事。

### 方法 2：分享 Claude 對話連結

**成本**：很低 | **震撼度**：中

Claude 可以讓你分享整段對話，包括 Artifact。

1. 在 Claude 對話裡，點擊右上角的**分享**按鈕
2. 選擇「分享對話」或「建立分享連結」
3. 複製生成的網址
4. 發給任何人 -- 他們可以看到你的對話**和**你的 Artifact

**額外好處**：收到連結的人可以看到你的完整思考過程 -- 你的 Prompt、迭代、修改。這就像一部幕後花絮紀錄片。

### 方法 3：部署到 Netlify Drop

**成本**：中等 | **震撼度**：高

這個方法會讓人說：「等等，你有一個網站？？」

**Netlify Drop** 讓你把一個 HTML 檔案拖拉到它們的平台上，幾秒鐘就得到一個可以分享的網址。

**步驟：**

1. **取得 HTML**：在 Claude 裡，Artifact 做好之後說：
   > 「請把這個 Artifact 輸出成一個完整的 HTML 檔案。所有 CSS 和 JavaScript 都內嵌在同一個 HTML 檔案裡，讓我可以直接存下來用瀏覽器打開。」

2. **儲存檔案**：打開文字編輯器（Mac 用 TextEdit 記得先改成純文字模式），貼上 HTML 程式碼，存成 `index.html`。在桌面建一個資料夾叫 `my-project`，把 `index.html` 放進去。

3. **部署**：
   - 前往 [app.netlify.com/drop](https://app.netlify.com/drop)
   - 把 `my-project` 資料夾拖進去
   - 等 10-30 秒
   - 你會得到一個像 `https://magical-unicorn-abc123.netlify.app` 的網址
   - 就這樣。這是一個真正的網站。在真正的網路上。你做的。

4. **（選做）永久保存**：註冊免費 Netlify 帳號，「認領」你的網站，改一個好看的網址。

### 方法 4：讓 Claude 做展示簡報

**成本**：中低 | **震撼度**：中高

有時候你需要「報告」你的工具，不只是分享它。請 Claude 做一份簡報：

> 「幫我做一份 5 頁的展示簡報 Artifact，介紹我剛做的 WeeklyBot。包含：
> - 第 1 頁：標題頁，工具名稱和一句話描述
> - 第 2 頁：它解決什麼問題（用一個讓人有共鳴的場景）
> - 第 3 頁：怎麼使用（3 步驟流程加圖示）
> - 第 4 頁：工具運作中的模擬截圖
> - 第 5 頁：未來改進計畫
> 風格要像 YC Demo Day 的簡報。加上導航箭頭。」

## 取得回饋：迭代循環

把東西做出來、分享出去只是開始。真正的魔法在**回饋循環**裡。

### 怎麼收集回饋

把你的 MVP 拿給 3-5 個真實使用者試用，然後問他們三個問題：

1. **「你第一眼覺得這是做什麼的？」** -- 測試你的工具是否一目了然
2. **「用起來有沒有哪裡卡住？」** -- 找出你沒想到的使用障礙
3. **「如果可以加一個功能，你想要什麼？」** -- 讓使用者幫你寫 v2 路線圖

### 怎麼根據回饋迭代

| 回饋類型 | 怎麼處理 |
|---------|---------|
| 「我不知道這是幹嘛的」 | 改善標題和介紹文字 |
| 「XX 按鈕壞了」 | 用第 5 章的修復技巧 |
| 「如果能 XX 就好了」 | 記下來，評估是否納入 v2 |
| 「我已經傳給三個同事了」 | 恭喜，你做到了 Product-Market Fit |
| 沒有任何人回覆 | 最殘酷但最有價值的回饋 -- 也許需要換個問題解決 |

### 分享心態

一個不舒服但重要的真相：**大多數做出東西的人從來不分享。**

他們覺得「還沒準備好」。覺得「不夠好」。怕別人批評。然後他們的作品就靜靜躺在一個瀏覽器分頁裡，直到分頁被關掉，世界因此少了一點點有趣。

不要當那種人。你的 MVP 不是一件藝術品 -- 它是一個對話的起點。每一條回饋都讓下一個版本更好。每一個看到它的人都可能有一個你從沒想過的點子。

早一點分享。常常分享。不完美地分享。
