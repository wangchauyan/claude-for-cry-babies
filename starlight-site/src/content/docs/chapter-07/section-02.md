---
title: "7.2 哭包選題指南：什麼點子適合拿 Claude 做？"
---


不是所有點子都適合用 Artifacts + Claude 來做 MVP。選對題目，你的週末會很愉快；選錯題目，你的週末會很想哭。

## ✅ 適合的

| 類型 | 範例 |
|------|------|
| **互動計算工具** | 房貸計算機、BMI 計算器、匯率轉換器 |
| **內容產生器** | 週報產生器、自我介紹產生器、面試題產生器 |
| **資料視覺化** | 個人財務儀表板、專案進度追蹤器 |
| **教學互動** | 九九乘法練習、單字卡、Quiz 測驗 |
| **小遊戲** | 猜數字、記憶翻牌、Wordle 變體 |

## ❌ 不適合的

| 類型 | 為什麼不行 |
|------|-----------|
| **需要登入系統** | Artifacts 沒有使用者認證 |
| **需要資料庫** | Artifacts 不能永久儲存資料 |
| **需要即時通訊** | 不能連外部 API |
| **需要付款功能** | 涉及金流安全性太複雜 |
| **需要操作手機** | Claude 只活在瀏覽器裡 |

## 選題練習

從你日常的三個痛點中，選出最適合 AI 實作的那個。問自己：

1. **這個問題夠痛嗎？** — 你（或你認識的人）真的會用嗎？
2. **一句話能說清楚嗎？** — 「一個可以 _____ 的工具」
3. **能用 Artifacts 做嗎？** — 對照上面的 ✅ / ❌ 清單

如果三個答案都是 Yes，恭喜你找到了你的 MVP 題目。
