title: "7.7 如何分享你的作品？"
---


做出了一個酷東西，當然要讓別人看到。以下是四種分享方式，從最簡單到最「專業」。

## 方法 1：截圖 / 螢幕錄影

**難度**：⭐（最簡單）

直接對 Artifacts 截圖，或用螢幕錄影（Mac 用 `Cmd + Shift + 5`）錄一段操作示範。

**適合**：在 Line 群組、Slack 頻道分享給朋友看。

## 方法 2：分享 Claude 對話連結

**難度**：⭐⭐

如果你的對話是「公開」的，可以點擊對話右上角的分享按鈕，生成一個連結。

**適合**：讓別人看到你的完整對話流程（包括怎麼跟 Claude 溝通的）。

## 方法 3：把 HTML 放到免費 Hosting

**難度**：⭐⭐⭐

如果你想讓作品真正「上線」，可以把 Artifacts 的程式碼部署到免費的 hosting 服務。

### 最簡單的方式：Netlify Drop

1. 在 Artifacts 裡複製 HTML 程式碼
2. 把它存成 `index.html` 檔案
3. 前往 [app.netlify.com/drop](https://app.netlify.com/drop)
4. 把檔案拖進去
5. 完成！你得到一個可以分享的網址

**適合**：想讓任何人都能透過網址使用你的工具。

## 方法 4：讓 Claude 幫你做展示用的簡報

**難度**：⭐⭐

> 「我做了一個週報產生器（附上截圖）。請幫我做一份 5 頁的展示簡報，包含：
> 1. 問題描述（為什麼需要這個工具）
> 2. 解決方案（我的工具做了什麼）
> 3. 操作截圖（我會自己插入截圖的位置）
> 4. 使用者回饋（先用假的，正面的）
> 5. 下一步計畫
>
> 風格要像 YC Demo Day 的簡報。」

**適合**：跟老闆或投資人展示你的點子。
