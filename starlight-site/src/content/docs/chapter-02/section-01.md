讓我們來看看新手最常犯的錯誤。

## 餐廳比喻（強化版）

如果你去餐廳只跟服務生說「我要吃飯」，你可能會得到：
- 一碗白飯
- 一盤義大利麵
- 一碗服務生自己愛吃的螺螄粉

服務生不是故意整你。他很認真地端了「食物」來——技術上來說，他完成了任務。但那不是你想要的東西。

如果你說「我要鼎泰豐的小籠包、微辣、不加蒜、多給一碟醋」，你得到你想要的東西的機率就是 99%。

同一間餐廳、同一個廚房，結果天差地遠。

**跟 AI 溝通也是一樣。**

當你對 Claude 說「幫我寫封 Email」，Claude 就是那個聽到「我要吃飯」的服務生。它會給你*一封* Email。但那封 Email 是不是你要的，那就純靠運氣了。

## Before / After 對比

讓我們看一個真實的例子，感受一下差距有多大。

### ❌ 菜鳥版

```
幫我寫一個遠端工作的提案給老闆。
```

**Claude 的輸出**：一篇像維基百科的通用文章，三個段落講遠端工作的好處。沒有個性，誰寫給誰都適用。你的老闆看了會覺得你在交作業。

### ✅ 哭包進化版

```
幫我寫一份一頁的提案給我的直屬主管（營運副總，
看數據說話那種人，對遠端工作持懷疑態度）。

目標：爭取每週 2 天遠端的試辦方案，
對象是我們 12 人的客服團隊。

請包含：
- 3 個數據點，證明遠端工作能提升客戶滿意度
- 回應他最可能的質疑：「我怎麼知道大家真的有在做事？」
- 提出 90 天試辦期 + 明確的成功指標
- 語氣：尊重但有信心，不要太業務員
- 長度：一頁以內，用條列式（他討厭長段落）
```

**Claude 的輸出**：一份精準有力的提案，讀起來像你花錢請了顧問寫的。它針對了那位特定主管的疑慮，附上了相關數據，還有明確的行動呼籲。

同一個 AI，同一個免費帳號。差別完全在於你怎麼問。

## 萬能溝通公式：CRISPE

好，「給多一點資訊」是不錯的建議，但它本身就很模糊。（有沒有很諷刺？）讓我們來一個具體的框架。

**CRISPE** 是一個幾乎適用於所有任務的 prompt 公式。每次寫 prompt 前，想想這六個字母：

| 字母 | 代表 | 白話翻譯 | 範例 |
|------|------|----------|------|
| **C** | Capacity（角色） | 你要 Claude 扮演誰？ | 「你是一位資深 HR 顧問」 |
| **R** | Request（任務） | 你要它做什麼？ | 「幫我寫一份行銷經理的職缺描述」 |
| **I** | Insight（背景） | 它需要知道什麼背景？ | 「我們是 50 人的 B2B SaaS 新創，這個角色直接向 CMO 報告」 |
| **S** | Style（格式） | 輸出要什麼格式？ | 「用條列式，不超過 400 字」 |
| **P** | Personality（語氣） | 文字的口吻？ | 「專業但親切。我們不是古板的大企業。」 |
| **E** | Experiment（限制） | 什麼不要做？ | 「職稱不要用『忍者』或『搖滾巨星』。不要用行話。」 |

你不需要每次都填滿六項。但用得越多，結果就越好。

## CRISPE 實戰：完整範例

把整套公式串在一起用。假設你要寫一封客戶道歉信。

### 沒用 CRISPE

```
幫我寫一封給客戶的道歉信。
```

*結果：超級通用，放在任何公司、任何情境都適用。也就是說——對你的情境完全沒用。*

### 用了 CRISPE

```
**角色 (C)**：你是一家中型電商公司的客戶成功經理，
公司賣的是高級廚房用品。

**任務 (R)**：寫一封道歉信給一位客戶，他的訂單遲到
了 5 天，而且有一個陶瓷沙拉碗到貨時已經破損。

**背景 (I)**：這位客戶是回購客（第 4 次下單），而且
在我們網站上留了一則憤怒的評論。我們很想留住他。
我們可以提供全額換貨 + 下次訂單打 8 折。

**格式 (S)**：短信（200 字以內）。結構要清楚：
先承認問題、解釋原因（倉庫積壓，不是藉口）、
說明補救方案、溫暖收尾。

**語氣 (P)**：真誠、有人味。不要公關稿。
不要道歉超過三次（第三次之後就顯得很假了）。

**限制 (E)**：不要用「我們非常重視您的惠顧」
（老套死了）。不要甩鍋給物流公司。
```

*結果：一封完美校準的道歉信，你可以直接點發送。*

## 不用死背字母

認真說，不要為了記住 C-R-I-S-P-E 的順序而緊張。這個框架存在的意義是提醒你「哪些類型的資訊」可以讓 prompt 變好。實務上，每次打字之前問自己這五個問題就好：

1. **誰** — Claude 應該扮演什麼角色？
2. **做什麼** — 我具體需要什麼？
3. **為什麼** — Claude 需要知道什麼背景？
4. **怎麼做** — 輸出要長什麼樣、聽起來什麼感覺？
5. **不要做什麼** — 有什麼禁區？

如果你的 prompt 回答了這五個問題，你已經是前 10% 的 AI 使用者了。沒有在誇張。

## 「陌生人測試法」

這裡有一個快速檢查法：**把你寫的 prompt 當作是一個完全不認識你的陌生人在讀。**

這個陌生人知不知道：
- 這個輸出是給誰看的？
- 目標是什麼？
- 「做得好」長什麼樣？
- 有什麼限制條件？

如果陌生人看不懂，就補更多細節。Claude 就是那個陌生人。一個聰明的、很想幫忙的陌生人——但終究是個陌生人。

## 常見 Prompt 錯誤（和修正方法）

| 錯誤 | 問題在哪 | 怎麼修 |
|------|---------|--------|
| 太模糊 | 「幫我做個簡報」 | 指定：主題、對象、長度、格式、目標 |
| 一次塞太多任務 | 「寫我的履歷，順便分析數據，再做個網站」 | 一次一個任務（或至少清楚分段） |
| 沒指定對象 | 「寫一篇部落格文章」 | 「寫一篇給剛開始做社群行銷的小型企業主看的部落格文章」 |
| 沒給語氣 | 「寫一則公告」 | 「寫一則公告，語氣要興奮但不浮誇」 |
| 假設它有上下文 | 「更新上次那個東西」 | Claude 不記得上次。重新說一遍背景。 |

## 現在就試試看

拿一個你最近想叫 AI 做的事情，用 CRISPE 重寫一次。你會馬上看到差別。

想不到？試試這個練習：

**原始 prompt**：「幫我寫一則 LinkedIn 升職貼文。」

**你的 CRISPE 改寫版**：*（把每個元素填上你的真實情況。提示：你是什麼產業的？升到什麼職位？你是想低調炫耀還是真心感恩？你想要那種釣互動的文還是真誠的分享？）*
