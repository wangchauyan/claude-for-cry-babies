# 1.4 動手時間：你的第一次對話

理論講完了，是時候動手了。請打開 [claude.ai](https://claude.ai)。

## 完整流程

1. 打開瀏覽器，前往 `claude.ai`
2. 註冊或登入（免費帳號就可以開始）
3. 你會看到一個對話框，就像 Line 或 Messenger 一樣
4. 在下面的輸入框打字，然後按 Enter

就這樣。沒有要你安裝任何東西。

## 三個由淺入深的入門 Prompt

### Prompt 1：打招呼（熱身）

> 「嘿 Claude，我是一個完全不懂程式的上班族。我聽說你可以幫我做很多事情，但我有點緊張。請用最白話的方式告訴我，你今天能幫我做什麼最簡單的小事？」

試試看，你會發現它的回答溫暖得讓你想哭（不要真的哭）。

### Prompt 2：做一件有用的事

> 「請幫我寫一封跟老闆請假的 Email。理由是家裡有事需要處理，語氣要禮貌但不卑微，長度控制在 100 字以內。」

看到了嗎？你給了它：角色背景（請假）、具體要求（禮貌但不卑微）、限制條件（100 字）。這就是好的溝通。

### Prompt 3：見識 Artifacts 的威力

> 「請用 Artifacts 幫我做一個簡單的倒數計時器。可以設定分鐘數，按開始就會倒數，時間到了會有提醒。介面要好看，用柔和的藍色系。」

如果一切順利，你的畫面右側會出現一個**真的可以用的倒數計時器**。

恭喜你，你剛剛做出了人生第一個「App」。

## 🔨 週報產生器 v0.1

在結束這一章之前，讓我們開始建造貫穿全書的專案。

請對 Claude 說：

> 「我想做一個週報產生器。請先幫我想一個適合上班族的週報格式，包含：本週完成事項、下週計畫、遇到的困難、需要的支援。請用 Markdown 格式輸出。」

把 Claude 給你的結果**複製起來，存到你的筆記裡**。這是你的第一個產出，後面每一章我們都會讓它進化。
