# 6.4 進階用法：用 Projects 管理不同面向的生活

Projects 不只是用來工作的。你可以為生活的每個面向建立一個 Project。

## 我的 Projects 清單（範例）

### Project 1：工作週報與商務溝通
- **上傳文件**：公司簡介、職位描述、過去的週報、Email 範例
- **Custom Instructions**：專業、簡潔、結論先行
- **用途**：每週寫週報、回覆老闆 Email、準備會議大綱

### Project 2：Side Project 開發
- **上傳文件**：產品規格書、wireframe 截圖、技術筆記
- **Custom Instructions**：用最簡單的技術方案、Artifacts 優先、分步驟做
- **用途**：用 Claude 做 MVP、debug、迭代功能

### Project 3：學英文 / 考證照
- **上傳文件**：考試大綱、過去的錯題、學習進度表
- **Custom Instructions**：用英文回答、每次對話結束後給我三個新單字、如果我的英文有錯直接糾正
- **用途**：每日練習、模擬考題、檢討錯題

### Project 4：理財分析
- **上傳文件**：個人資產配置表、關注的股票清單
- **Custom Instructions**：客觀分析、不給投資建議（只給分析框架）、用數據說話
- **用途**：分析財報、追蹤持股、比較 ETF

## 為什麼要分開？

每個 Project 都有自己的**上下文**和 **Custom Instructions**。

如果你把所有東西塞在一個 Project 裡，Claude 會混亂 —— 它可能在你問工作問題時突然用「學英文模式」的語氣回答。

分開的好處：
- 每個 Project 的 Claude 都「專精」一個領域
- 切換 Project 就像切換你的「助理」
- 參考文件不會互相干擾
