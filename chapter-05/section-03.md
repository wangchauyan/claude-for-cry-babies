# 5.3 三個最常見的 Artifacts 錯誤 + 修復對話實錄

以下是三個你很可能會遇到的真實錯誤。

---

## Case 1：React 元件沒有 default export

### 錯誤訊息
```
Error: The default export is not a React Component
```

### 白話翻譯
Claude 寫了一個元件，但忘了在最後「匯出」它。就像你寫了一封信但忘了放進信封，郵差不知道要寄什麼。

### 修復 Prompt
> 「出現 "default export is not a React Component" 錯誤。請確保元件有正確的 default export，然後重新生成。」

### Claude 的反應
它會加上 `export default function App()` 然後重新生成。問題解決。

---

## Case 2：CSS 跑版（排版亂掉）

### 症狀
畫面出來了，但東西亂七八糟 — 按鈕跑到畫面外面、文字重疊在一起、手機版看不到一半的內容。

### 白話翻譯
「設計圖看起來很好，但實際蓋出來歪了。」

### 修復 Prompt
> 「排版有問題：
> - 按鈕跑到右邊畫面外面了，應該要在中間
> - 兩段文字重疊在一起，應該要有間距
> - 請確保整個畫面在 375px 寬度（手機）也能正常顯示
>
> 請用 flexbox 排版，確保元素正確對齊。」

### 關鍵
描述排版問題時，說**「什麼在哪裡」+「應該在哪裡」**比說「排版壞了」有效 100 倍。

---

## Case 3：功能只做了一半

### 症狀
你要求做三個功能，Claude 只做了兩個。第三個按鈕存在，但點了沒反應。

### 白話翻譯
Claude 在寫到一半的時候「累了」或者 Token 用完了。

### 修復 Prompt
> 「你漏掉了一個功能：『匯出 Markdown』按鈕。點擊後應該要：
> 1. 把目前的內容轉換成 Markdown 格式
> 2. 複製到剪貼簿
> 3. 顯示一個『已複製！』的提示
>
> 請補上這個功能。其他已完成的部分不要動。」

### 關鍵
明確說**「其他部分不要動」**，否則 Claude 可能會「順便」改了你已經滿意的部分。
