# 第 4 章：檔案分析 — Claude 最被低估的超能力

> *Claude 不只會聊天，它是你的私人數據分析師、文件翻譯官、圖片解讀器。*

---

大部分人把 Claude 當成「聊天機器人」，只用它來問問題。但你知道嗎？它能直接讀你的 Excel、分析你的 PDF、甚至看懂你隨手截的螢幕截圖。

這一章要教你的技能，是你明天上班就能用的 —— 把那些你看到就頭痛的數據和文件，丟給 Claude 三秒搞定。

你將學到：
- 上傳 Excel / CSV 做自動分析
- 上傳 PDF 一秒讀完五十頁
- 上傳圖片讓 Claude 解讀
- 用 Code Execution 讓 Claude 直接跑程式幫你處理資料
